Take TriageAI to the bedside. Real-time patient triage, clinical AI scoring, and EHR sync in the palm of your hand.

Android 8.0+ HIPAA Compliant AES-256 Encrypted Signed APK

Installation Instructions

  1. 1

    Enable Unknown Sources

    Go to Settings then Security and enable Install Unknown Apps for your browser or file manager.

  2. 2

    Download the APK

    Tap Download APK above. The file saves to your Downloads folder.

  3. 3

    Open and Install

    Open the file and tap Install. Tap Install Anyway if prompted.

  4. 4

    Sign In

    Launch TriageNative and sign in with your TriageAI membership credentials. Active subscription required.

System Requirements

  • Android 8.0 (Oreo) or higher
  • 100 MB free storage
  • Internet connection required
  • Active TriageAI subscription
  • Camera permission optional for patient ID scan

Security and Compliance

  • Signed release APK production keystore
  • AES-256 data encryption
  • HIPAA-compliant data handling
  • No PHI stored locally on device
  • Certificate pinning enabled
