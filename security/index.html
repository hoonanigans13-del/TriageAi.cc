Security

How we protect the ledger

The integrity of the Civic Intelligence Ledger depends entirely on the security of the infrastructure that runs it. Here is how we approach that responsibility.

🔐

Cryptographic Chaining

Every ledger entry is hashed and linked to the previous entry. Modification of any record breaks the chain and is immediately detectable.

🔒

Encryption at Rest & in Transit

All ledger data is encrypted at rest using AES-256. All data in transit is protected by TLS 1.3. No exceptions.

🛡️

Access Control

Access to ledger infrastructure is role-based, logged, and requires multi-factor authentication. No single party can access the full ledger unilaterally.

🔍

Continuous Monitoring

Infrastructure is monitored 24/7 for anomalous access patterns, integrity failures, and unauthorized changes.

Responsible Disclosure

Found a vulnerability?

We take security reports seriously. If you discover a vulnerability in triageai.cc or the Civic Intelligence Ledger platform, please report it privately before public disclosure.

📬 Security Reports

Email: security@triageai.cc — PGP key available on request.

⏱ Response Time

We aim to acknowledge security reports within 48 hours and provide a resolution timeline within 7 days.

🤝 Safe Harbor

We will not pursue legal action against researchers who report vulnerabilities in good faith, follow responsible disclosure practices, and do not access or modify user data.
